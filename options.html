Anthropic API key

Your key is stored only in this browser (chrome.storage.local) and is used only to call the Anthropic Messages API directly from your browser at api.anthropic.com, to generate a tailored resume summary and cover letter for each job. It is never sent anywhere else, and never to any server we run — there is no third-party backend in this extension.

You can get an API key from the Anthropic Console. This extension does not create an account for you and does not work without your own key.
